첫 공개 릴리스입니다. 0.1~0.5는 개발 중 실차 시험판이었고, 바뀐 점을 모아 적습니다.

### 기능
- 내비게이션과 기본 앱 전체의 시스템 글꼴(Roboto, OEM 기본 글꼴, 한글 대체 글꼴)을 Pretendard 1.3.9로 바꿉니다. 런처 첫 화면과 앱 목록은 바뀌지 않습니다.
- `/system`을 고치지 않는 bind mount 방식입니다. Uninstall이나 NEMESIS 삭제 후 재부팅하면 순정입니다.
- 상태 화면(NEMESIS Manager → Launch):
  - 적용 상태와 적용 안 된 이유
  - 진단 실행: 1분 안팎, 9단계 진행 표시, 중지, USB 분리 감지
  - GitHub 이슈 QR: 차 정보가 미리 채워집니다.
- 안전장치:
  - 늦게 시작하면 걸지 않습니다.
  - 부팅이 연속 2번 정상적으로 끝나지 않으면 스스로 꺼집니다.
  - 손상된 글꼴은 건너뜁니다.

### 실차에서 다듬은 것
- 부팅 때 마운트 시간을 1.8초에서 0.45초로 줄였습니다. 이제 글꼴 로딩보다 약 1.6초 먼저 끝납니다.
- 진단 결과에서 시리얼, BT·Wi-Fi·MAC 주소, 사용자 파일 이름, logcat 원본을 뺐습니다.
